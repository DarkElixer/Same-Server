# IPTV Design System

## Vision

Modern dark glassmorphism IPTV UI with yellow accent.

## Colors

-   Background: #0B1117
-   Surface: #111820
-   Card: #1A232C
-   Accent Yellow: #FFC107
-   Accent Teal: #2A7D8F
-   Text Primary: #FFFFFF
-   Text Secondary: #A7B0BB
-   Border: #2A333E

## Typography

-   Font: Poppins
-   Display: 32px Semibold
-   Heading: 20px Medium
-   Title: 16px Medium
-   Body: 14px Regular
-   Caption: 12px Regular

## Components

-   Glass cards with 16--24px radius.
-   Large category cards: Live TV, Movies, Series.
-   Top-right settings and profile.
-   Soft blur, subtle shadows.
-   Selected state uses yellow glow.

## Spacing

8px grid. Radii: 8/16/24/32px.

## Agent Instructions

Update the existing website to match this design system without changing
functionality. Preserve routing and backend APIs. Implement reusable
design tokens. Use CSS variables or Tailwind theme. Ensure responsive
TV, desktop and tablet layouts.
